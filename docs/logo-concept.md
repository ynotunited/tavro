# TAVRO LOGO CONCEPT

---

## STRATEGIC BRIEF

Tavro's logo must communicate:

- **Control** — Organized, structured, intentional
- **Flow** — Operations moving smoothly
- **Hospitality** — Human, trustworthy, professional
- **Transactions** — Clear, final, certain
- **Visibility** — Clarity, insight, intelligence

### What to Avoid

- Fork, knife, spoon, plate (obvious restaurant clichés)
- Chef hat, wine glass, generic "T" (overdone)
- Abstract blob, generic symbol (unmemorable)
- Overly complex or intricate (doesn't scale down)
- Trendy geometric or gradients (dates quickly)

### Design Principles

1. **Simplicity** — Works at 16px and 1000px
2. **Distinctiveness** — Recognizable in hospitality space
3. **Timelessness** — Looks serious in 2035
4. **Scalability** — Monochrome, color, inverted, dark mode
5. **Professional** — Premium without pretension

## LOGO DIRECTIONS

### DIRECTION 1: "THE PLATE"
**Concept:** Circular plate divided into quadrants, each representing an operational function

```
┌─────────────────┐
│   │      │      │
│ P │  O   │  S   │
│   │      │      │
├───┼──────┼──────┤
│   │      │      │
│ I │  N   │  V   │
│   │      │      │
└─────────────────┘
```

**Structure:**
- Circle represents the restaurant/hospitality venue
- Four quadrants represent: POS, Operations, Staff, Intelligence
- Central intersection shows connection/integration
- Subtle separator lines create structure without noise

**Color Application:**
- Charcoal base circle outline
- Amber highlights in quadrant separators
- Minimal, professional

**Advantages:**
- Immediately connectable to hospitality
- Shows "4 pillars" of Tavro
- Circular (whole system, complete)
- Scales well

**Disadvantages:**
- Still somewhat restaurant-related
- Quadrant division could feel arbitrary
- Risk: Looks like food service diagram

**Rating:** 6/10 (Good but slightly on-the-nose)

---

### DIRECTION 2: "OPERATIONAL FLOW" ⭐ RECOMMENDED
**Concept:** Horizontal flow of transaction nodes showing operations, control, clarity

```
●────●────●────●
 ╲   │    ╱  ╱
  ╲  │   ╱  ╱
   ╲ │  ╱  ╱
    ●────●
     (control point)
```

**Structure:**
- Three or four interconnected nodes/circles
- Nodes represent transaction points, operational checkpoints
- Horizontal flow suggests time, sequence, transaction
- Central lower node (hub) represents control/visibility
- Subtle lines show connection without clutter

**Execution:**
- Nodes: Charcoal circles
- Connecting lines: Amber (showing "active flow")
- Clean, minimal stroke weight (1–1.5px)

**Simplified version for app icon:**
```
●──●──●
 ╲ │ ╱
  ●●●
   (creates a star-like form)
```

**Advantages:**
- Abstract but immediately connectable to operations
- Represents "flow" and "control" without being obvious
- Works at any size (app icon to billboard)
- Distinctively Tavro
- Not a hospitality cliché
- Scales beautifully in monochrome
- Works in color, inverted, on dark backgrounds
- Professional and modern without being trendy

**Disadvantages:**
- Requires clear explanation initially
- Could be misinterpreted as network/tech diagram
- Needs careful execution to avoid looking like generic diagram

**Rating:** 9/10 (Strong, distinctive, operationally connected)

---

### DIRECTION 3: "TRANSACTION CHECKPOINT"
**Concept:** A single geometric form suggesting a checkpoint, control point, or transaction moment

```
┌─────┐
│  ✓  │    (point of control/clarity)
└─────┘
```

**Structure:**
- Clean rectangle or rounded square
- Central checkmark or point indicator
- Suggests "transaction complete," "control confirmed"
- Could incorporate subtle grid lines (operational precision)

**Simplified:** Single geometric shape with strategic line weight

**Advantages:**
- Minimal and strong
- Represents transaction/checkpoint
- Very scalable
- Professional
- Modern

**Disadvantages:**
- Risk of being too generic (looks like every B2B app)
- Less distinctive than Direction 2
- Could feel corporate/cold

**Rating:** 6/10 (Safe but less distinctive)

---

## RECOMMENDED DIRECTION: DIRECTION 2 (OPERATIONAL FLOW)

### Why This Wins

1. **Distinctiveness** — You won't confuse Tavro with any other hospitality tech company
2. **Operational Logic** — The symbol communicates what Tavro does (connect operations, create flow, provide control)
3. **Scalability** — Works perfectly at 16px app icon, 200px website, 1000px signage
4. **Timelessness** — Not trendy. Will look serious and intentional in 2035
5. **Monochrome Power** — Looks great in single color without losing identity
6. **International** — Doesn't rely on cultural references or visual clichés
7. **Flexibility** — Adapts to dark mode, light mode, print, digital seamlessly

## FINAL LOGO SPECIFICATION

### PRIMARY LOGO

**Structure (Operational Flow):**
```
●────●────●     (three operational nodes)
 ╲   │    ╱      (downward flow/connection)
  ╲  │   ╱
   ╲ │  ╱
    ●●●          (convergence point - control/visibility)
```

**Refined version:**
- Three circles (Ø 5 units) connected by horizontal line
- Three diagonal lines flowing downward from outer circles
- Central point where diagonals converge (Ø 5 units)
- Creates dynamic but ordered visual

**Color Application:**
- **Charcoal nodes and flow lines** (#1F2937)
- **Amber primary connecting line** (#D97706)
- Minimal, intentional color usage

**Execution:**
- Stroke weight: 1.5px
- Corner: Sharp (professional, not rounded)
- Spacing: Precise 8-unit grid
- Proportions: Golden ratio-inspired balance

### WORDMARK

**Typeface:** See typography.md (Likely: Inter or IBM Plex Sans)
**Style:** All caps or sentence case (TBD based on typography direction)
**Spacing:** Tight, professional
**Color:** Charcoal, never reversed on amber alone

```
T A V R O
```

**Never:**
- Gradient text
- Outline/hollow letters
- Overly stylized
- Disconnected from symbol

**Horizontal Lockup (Primary):**
```
    ●────●────●
     ╲   │    ╱      T A V R O
      ╲  │   ╱
       ╲ │  ╱
        ●●●
[Symbol] [Wordmark]
```

**Stacked Lockup (Secondary):**
```
    ●────●────●
     ╲   │    ╱
      ╲  │   ╱
       ╲ │  ╱
        ●●●

    T A V R O
[Symbol above wordmark]
```

**Logo Only (Symbol):**
Used for app icons, favicons, small applications

**Monochrome (Primary):**
Charcoal on white, white on charcoal, single color applications

**Reversed:**
Amber symbol on charcoal background
Off-white on charcoal background

---

### CLEAR SPACE & MINIMUM SIZE

**Clear Space:**
- Minimum clear space around entire logo: 1/4 of symbol height
- No competing visual elements within clear space
- Tighter on web, more spacious in print

**Minimum Size:**
- Web: 80px (width)
- App: 40px (icon size, with padding)
- Print: 1 inch (25.4mm)
- Below minimum: Use symbol only, not full lockup

## GLOSSARY OF TERMS

**Brand Promise:** "Hospitality, under control" — what Tavro delivers emotionally

**Design Tokens:** Semantic variables (colors, spacing, type) for consistent implementation

**Lockup:** Logo + wordmark together in a defined layout

**Primary Tagline:** "Sell more. Control stock. Know your numbers" — core positioning

**Tavro:** Operating system for hospitality (restaurants, bars, clubs, hotels)

**Value Proposition:** Specific benefit to a customer segment

**Wordmark:** Text-only version of brand name

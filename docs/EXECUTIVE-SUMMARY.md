## VISUAL IDENTITY

### Logo
**Direction:** Operational Flow (three nodes connected showing transaction flow and control)

```
●────●────●     (three operational checkpoints)
 ╲   │    ╱
  ╲  │   ╱
   ●●●          (convergence point - control/visibility)
```

- **Clean, professional, scalable** (works at 16px to 1000px)
- **Distinctive** (not a restaurant cliché)
- **Memorable** (operationally connected to what Tavro does)
- **Timeless** (will look serious in 10 years)

### Colors
**Direction:** Charcoal + Amber (Premium Nigerian Hospitality)

| Color | Hex | Purpose |
|---|---|---|
| Charcoal | #1F2937 | Primary brand, text, operations foundation |
| Amber | #D97706 | Secondary, CTAs, visibility, warmth |
| Off-White | #FAFAFA | Backgrounds, light surfaces |
| Emerald | #059669 | Success, confirmations |
| Red | #DC2626 | Errors, critical alerts |

**Why this palette:**
- ✅ Charcoal is professional, works on dark POS screens
- ✅ Amber is inherently warm (hospitality) and functional (visibility/light)
- ✅ Not trendy. Not purple/blue AI cliché. Distinctly Tavro.
- ✅ Works in nightclub environments, premium settings, light dashboards
- ✅ All combinations meet WCAG AA accessibility minimum

### Typography

| Font | Usage | Why |
|---|---|---|
| Inter | Primary font (UI, headings, body) | Engineered for screens, neutral, professional |
| IBM Plex Mono | Numeric data (amounts, time, reference codes) | Monowidth ensures alignment, high contrast |

**Scale:**
- H1: 32px, Bold
- H2: 24px, Bold
- H3: 20px, Semi-Bold
- Body: 14px, Regular, 1.6 line height
- Numbers: 16–24px, Semi-Bold, Monospace

**Principle:** Clear hierarchy. Maximum 14px body on POS for legibility. Numbers must be instantly readable.

## VISUAL STANDARDS

### UI Direction

**POS Interface (Dark Mode):**
- Dark background (#0F172A)
- Off-White text (#FAFAFA)
- Amber Light CTAs (#FBBF24)
- Numbers in monospace, 24px+
- Touch targets 48px minimum
- No animations, immediate feedback

**Manager Dashboard (Light Mode):**
- Off-White background (#FAFAFA)
- White cards (#FFFFFF)
- Charcoal text (#1F2937)
- Amber accents
- Clean tables and charts
- Real-time updates

**Mobile App:**
- Bottom navigation tabs
- Card-based layouts
- 44px minimum touch targets
- Responsive 375px to 768px

### What NOT to Do
❌ Gradients
❌ Rounded cards with heavy shadows
❌ Decorative effects
❌ Glassmorphism or neumorphism
❌ 3D effects
❌ Excessive animations
❌ Neon colors
❌ Small fonts

## QUICK REFERENCE

### When to Use Colors

| Color | Use Cases |
|---|---|
| Charcoal | Primary text, headings, backgrounds, operations foundation |
| Amber | CTAs, highlights, key actions, visibility accents |
| Off-White | Light backgrounds, light surfaces |
| Emerald | Success states, confirmations, positive feedback |
| Orange | Warnings, requires attention |
| Red | Errors, critical alerts, deletions |

### When to Use Typography

| Typeface | Use |
|---|---|
| Inter | Everything except numbers (headings, body, labels, UI) |
| IBM Plex Mono | Numbers, amounts, time, reference codes, receipts |

### Button Hierarchy

**Primary Button** (amber bg, charcoal text)
- Main actions (Save, Confirm, Pay, Send)
- One per screen max

**Secondary Button** (transparent, border)
- Alternative actions (Cancel, Skip, Learn More)
- Multiple allowed

**Danger Button** (red bg, white text)
- Destructive actions only (Delete, Refund, Void)
- Requires confirmation

## FINAL WORD

This brand system is **not decorative**. Every choice is strategic.

- **Charcoal + Amber** because it's distinctive, professional, and functional—not trendy
- **Sharp corners** because operational systems are precise, not soft
- **Inter + IBM Plex Mono** because clarity and readability matter in hospitality
- **Minimal UI** because POS speed and dashboard density require functional design

**Tavro is not another startup. It's serious operational infrastructure.**

This brand system reflects that.

# TAVRO LOGO USAGE GUIDELINES

---

## LOGO LOCKUP RULES

### When to Use Each Lockup

**Horizontal Lockup (Primary)**
- Websites (header, footer)
- Business cards
- Presentations
- Email signatures
- Marketing materials
- Minimum width: 120px

**Stacked Lockup (Secondary)**
- App store pages
- Print materials with height constraints
- Social media (LinkedIn banner)
- Email footers with limited width
- Minimum width: 100px

**Symbol Only**
- App icons (iOS, Android)
- Favicons
- Small web buttons
- Social profiles
- Minimum size: 32px

## COLOR APPLICATIONS

### Primary (Recommended)
**Charcoal symbol + Charcoal wordmark**
```
Color: #1F2937
Background: White, Light Gray, Light Blue
Use: 95% of applications
```

### Secondary
**Amber symbol with Charcoal wordmark**
```
Symbol: #D97706
Wordmark: #1F2937
Background: White or Off-White (#FAFAFA)
Use: Special emphasis, hero sections
```

### Reversed (Dark Backgrounds)
**White symbol + White wordmark**
```
Color: #FAFAFA
Background: Charcoal (#1F2937), Dark (#0F172A)
Use: Dark mode, dark websites, signage, uniforms
```

### Monochrome (Print/Single Color)
**100% black or 100% charcoal**
```
Color: #000000 (print) or #1F2937 (digital)
Use: Print materials where color unavailable
Background: White, light paper
```

### Do NOT Use These

❌ Gradient symbol (breaks cohesion)
❌ Amber symbol on charcoal wordmark (unbalanced)
❌ Symbol and wordmark in different colors (inconsistent)
❌ Rotated or skewed logo (unprofessional)
❌ Modified proportions or aspect ratio (distortion)
❌ Logo with drop shadows or effects (cheap-looking)
❌ Logo with background shapes (unnecessary)

## SIZING & SCALING

### Minimum Sizes

| Application | Minimum Width | Notes |
|---|---|---|
| Website header | 80px | Clear and sharp |
| App icon | 40px | Symbol only, with 4px padding inside frame |
| Favicon | 16–32px | Symbol only |
| Print: Business card | 1 inch (25.4mm) | Horizontal lockup |
| Print: Letterhead | 0.5 inch (12.7mm) | Can be smaller if positioned well |
| Signage | 6 inches (152mm) min | Maintain stroke weight proportions |
| Presentation slide | 80px (usually) | Top-left or bottom-left |

### Scaling Rules

- **Scale proportionally** — Maintain aspect ratio at all times
- **Preserve stroke weight** — When scaling down, stroke should remain visible (minimum 1px digital, 0.5pt print)
- **Never distort** — Do not stretch horizontally or vertically

## CLEAR SPACE REQUIREMENTS

**Clear space** is the minimum distance between the logo and other elements.

**Rule:** Minimum clear space = height of the wordmark cap height (or 1/4 of symbol height)

**Application:**
- Around all sides of the logo
- Between logo and body text
- Between logo and other visual elements
- Between logo and page edges (when possible)

**Visual example:**
```
        [clear space]
[clear space] TAVRO LOGO [clear space]
        [clear space]
```

## BACKGROUND USAGE

### Recommended Backgrounds

✅ **White** (#FFFFFF)
✅ **Off-White** (#FAFAFA)
✅ **Light Gray** (#F3F4F6)
✅ **Charcoal** (#1F2937) — White logo only
✅ **Dark** (#0F172A) — White logo only
✅ **Photography** — If contrast maintained (see contrast rules)

### Do NOT Use

❌ Busy patterns behind logo
❌ Competing colors (other than stated)
❌ Transparent/glass effect backgrounds
❌ Gradient backgrounds (unless very subtle)
❌ Logo directly on photo without contrast treatment

### Photo Backgrounds

If using Tavro logo on photography:
- Ensure minimum 4.5:1 contrast between logo and background
- Use a subtle solid-color overlay (charcoal at 20–30% opacity) behind logo
- Or use a white background circle/box with padding
- Test on actual photography before use

## ORIENTATION & POSITIONING

### Logo Orientation
- **Primary:** Horizontal or stacked (normal reading direction)
- **Never:** Rotated, flipped, or skewed
- **Never:** Angled or diagonal (except in very rare design instances)

### Positioning on Page

**Website Header:**
- Top-left: Horizontal lockup, 80px width minimum
- Vertically centered with navigation

**Website Footer:**
- Left-aligned or centered
- Can be smaller (60px) in footer context
- Maintains adequate clear space

**Email Signature:**
- Logo at bottom
- 60–80px width
- Can be stacked if width constrained

**Presentation Title Slide:**
- Bottom-right or top-right corner
- 80px width
- Maintains clear space from text

**Print Collateral:**
- Business cards: Logo-left, content-right (horizontal)
- Letterhead: Top-left or top-center
- Minimum 0.5 inch width

## ACCESSIBILITY IN LOGO

### Alt Text for Web

```html
<img src="tavro-logo.svg" alt="Tavro - Hospitality Operations Platform">
```

Not: "Logo" or "Image"
Use a clear, descriptive alt text

### Logo in Dark Mode

- Ensure white/light logo clearly visible on dark background
- Contrast minimum 4.5:1 (see accessibility.md)
- Test actual dark mode rendering

### Logo in High Contrast Mode

- Windows High Contrast Mode: Test that logo remains visible
- Monochrome logo should work in outline form
- Consider adding subtle outline for critical applications

## DIGITAL FILE FORMATS

### Deliverables

**Vector (Editable):**
- `tavro-logo.ai` (Adobe Illustrator)
- `tavro-logo.svg` (Web-optimized SVG)
- `tavro-logo.eps` (Print-ready)

**Raster (Fixed Size):**
- `tavro-logo@1x.png` (1x resolution, 256px width)
- `tavro-logo@2x.png` (2x resolution, 512px width)
- `tavro-logo-white@1x.png` (Light background version)
- `tavro-logo-white@2x.png` (Light background, 2x)

**App Icon:**
- `tavro-icon.png` (1024px, for app stores)
- Various sizes (180px, 192px, 512px for different platforms)

**Favicon:**
- `favicon.ico` (16x16, 32x32)
- `favicon.svg` (Scalable)

### SVG Specifications

```xml
<svg viewBox="0 0 200 200" xmlns="http://www.w3.org/2000/svg">
  <!-- Symbol: 200x200 logical units -->
  <!-- Stroke weight: 1.5px in logical units -->
  <!-- Colors: Use CSS classes for theming -->
</svg>
```

## COMMON MISTAKES TO AVOID

❌ **Scaling logo non-proportionally** — Always maintain aspect ratio
❌ **Using logo with background shapes** — Logo stands alone
❌ **Placing logo too close to content** — Violates clear space rules
❌ **Using too-small logo** — Becomes unreadable
❌ **Adding effects or drop shadows** — Cheapens brand appearance
❌ **Rotating or distorting logo** — Looks unprofessional
❌ **Using logo on competing colors** — Breaks contrast
❌ **Gradient or patterned logo** — Not permitted
❌ **Changing wordmark font** — Logo is locked, non-negotiable
❌ **Using old versions** — Keep library updated

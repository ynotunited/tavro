## COLOR APPLICATION GUIDE

### Light UI (Web, Dashboard)
- Background: Off-White (#FAFAFA)
- Text: Charcoal (#1F2937)
- Accents: Amber (#D97706)
- Borders: Light Gray (#E5E7EB)

### Dark UI (POS, Nighttime)
- Background: Dark (#0F172A)
- Surface: Dark Surface (#1E293B)
- Text: Dark Text Primary (#F8FAFC)
- Accents: Amber Light (#FBBF24)
- Borders: Dark Card (#334155)

### Print
- Primary: Charcoal (#1F2937)
- Accent: Amber (#D97706)
- Text: Charcoal/Medium Gray
- Backgrounds: Off-White (#FAFAFA)

### Signage
- Background: Charcoal (#1F2937)
- Text/Accent: Amber (#D97706)
- Secondary: Off-White (#FAFAFA)
